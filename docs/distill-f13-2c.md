## 3. Feature set and leakage controls

Features (pre-decision fields only, one labeled text block): `class`, `subject`,
`inputs`, `options`. NOT used as features: `choice` and `confidence` (post-decision —
the label source), `ts` and `id` (pure time/memorization handles; the by-order split
already encodes time). There is no `model` field in this corpus generation (the T70
shape is `id, ts, class, subject, inputs, options, choice, confidence`), so the named
feature set is the four pre-decision text fields above.

Leakage controls (requirement 2):

1. **Time-ordered split, never random** — the corpus is append-only, so file order IS
   chronology; train = first 80.0% of records, held-out = the last
   20.0%. No shuffle anywhere in the pipeline (the probe's shuffle is
   over TRAIN rows only, seeded).
2. **Near-duplicate dedup before the split** — key = (class, subject-shape,
   inputs-shape), digits→# and whitespace collapsed; first occurrence in file order
   kept. Measured: 0 exact-shape duplicates in
   `validation-routing` (none). Named inflation risk: subjects are templated
   (72 distinct subject shapes over 234
   records — e.g. "T<N> validation routing"), but held-out item ids are strictly newer
   than any train id, so the subject carries no reusable discriminator across the
   split; the discriminative text is `inputs`.
3. **Label source is the only post-decision field** — the mechanical rule (§2) reads
   `choice` to BUILD the label and nothing else; no post-decision field reaches the
   feature text.
4. **No held-out model selection** — the fine-tune trains a fixed 4 epochs
   and the LAST checkpoint is evaluated; the probe trains a fixed 60
   epochs. The primary head (probe) was chosen a priori on train-set size
   (186 examples cannot support full fine-tuning of a ~396M encoder), not on
   held-out numbers.

## 6. Threats to validity

- **Held-out n=47**: one record moves accuracy 2.1%; the probe's
  high-τ sliver (31 records at 77.4%) sits inside small-n
  noise at this n. Round 1's wiring bar wanted held-out n ≥ 60 — this split has
  47, so any high-τ point here carries 2.1%-per-record fragility
  (§7 weighs that in the verdict).
- **Label-rule catch-all (§2)**: the else→LANE arm labels
  89/233 dataset rows
  (38.2%) — most are genuine lane-eligible
  routings (the arm IS the LANE definition), but the four round-1-named off-task
  records sit in this run's dataset too (d1790471401-24 — a T78 doctrine-item DISPATCH record (its REQUIRED verdict lives in the inputs text; the choice says 'solo dispatch') (train row 7); d1790632587-1 — a goal_complete check-retry decision (no routing content) (train row 65); d1790734828-4 — a T161 dispatch-overlap decision (arguable REQUIRED; choice is '2-impl-overlap-t157+t159') (train row 87); d1790952238-1 — an eval-cycle phase-skip + queue-triage decision (train row 135)), and eval-cycle
  phase-skip/queue-triage subjects recur among them (2 of
  21 held-out catch-all rows); 21/47 held-out
  gold labels (44.7%) carry label noise from the arm —
  every accuracy number above, trained and mechanical side alike, carries it.
  Disclosed, never re-tuned.
- **Single split** (mandated by-order 80.0%/20.0%): no
  variance estimate across folds; a rolling-origin CV is the natural extension when
  the corpus grows.
- **Confidence is not calibrated**: softmax max-prob from a head trained on 186
  examples is a ranking signal, not a probability; the τ axis is a threshold on that
  ranking, and class weighting (rejected here to match the deployment prior) would
  shift it.
- **Templated prose**: all records come from one loop's writing style; a head trained
  on it may not transfer to other operators' phrasing (irrelevant for phase-3 wiring,
  which runs on this loop's own corpus).
- **Hardware nondeterminism**: seed 13 is pinned. Round 1's verification
  re-runs (same script, same device class) measured the wobble this round inherits:
  the probe and the mechanical baselines byte-identical every time, the fine-tune up
  to **5 held-out records** (≈17.2% accuracy at round 1's n=29; FT argmax 65.5%–82.8%
  observed across its re-runs) — at this round's n=47 the same 5-record wobble
  is ≈10.6%. This round re-ran the full script end-to-end during report
  regeneration: the probe, the baselines, and the τ-curve were byte-identical across
  runs, the fine-tune's argmax moved within the bound above; every headline number,
  the τ-curve, and the verdict rest on the deterministic probe + baselines, the FT
  row is directional (NOTE: this run landed at or above the majority baseline — the wobble straddles it).

## 7. Go/no-go for phase-3 confidence-gated wiring

**NO-GO** — the SAME robustness bar as round 1: a τ operating point
with ≥95% covered accuracy at ≥50% coverage on held-out n ≥ 60, carried by the
DETERMINISTIC probe (round-1 doctrine: headline numbers rest on probe + baselines; an
FT-only point cannot carry GO because the fine-tune's accuracy wobbles by up to 5
held-out records across same-device reruns, §6).

- **Corpus precondition (round-1 §7's, checked mechanically):** corpus 869 →
  2573 records (2.96×), outcome-labeled 216 →
  634 (2.94×) — the corpus-growth pace round 1 conditioned
  on, MET corpus-wide. The TASK class grew 142 → 234 (1.65×,
  below the ~3× / ~426 records the same precondition named): train n = 186
  (< 300), held-out n = 47 (< 60). The precondition's pooling alternative
  (pool adjacent routing classes) is NOT taken — the task is kept for like-for-like
  comparability (§1).
- **Wiring bar:** probe: no τ point reaches ≥95% accuracy at any coverage. An FT-side ≥95% point (none at any τ on either head)
  would not carry GO (wobble, above).
- **Baseline escape at full coverage:** probe 72.3% vs majority
  55.3% (+17.0pp); macro-F1
  0.687 vs 0.356 (+0.331).

**Verdict NO-GO** — no τ point on either head reaches ≥95% accuracy at ≥50% coverage (probe best covered: 77.4% at 66.0% coverage; FT argmax 78.7%); the task class grew 1.65× (under ~3×) and held-out n = 47 (< 60), so no wiring-grade point is reachable at this size. Until the bar is met: keep logging decisions (the corpus IS the asset), keep T199/T200 hygiene, and route validation with T189's mechanical predicate; the bar re-opens the day the validation-routing class reaches the round-1 size targets (~426 records, or pooled routing classes with train n ≥ 300 / held-out n ≥ 60) and this script's τ-curve shows the ≥95%@≥50% point on held-out n ≥ 60.
