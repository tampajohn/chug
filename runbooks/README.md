# Runbooks

One-page recipes for the recurring chug uses. Each names when to reach for
it, gives copy-pasteable commands (real flags; `<goal>` and `<N>` are the
only slots), and states its expected wall-clock arc so you can budget.
Pick the line that sounds like your situation:

- "I have one small chore and no spec" → [quick-task.md](quick-task.md)
- "I'm landing a real feature and want it validated" → [feature.md](feature.md)
- "Can chug drive some other repo? Evaluate it before committing a loop" → [repo-eval.md](repo-eval.md)
- "The self-improvement loop: start it, read it, stop it, recover it" → [loop-ops.md](loop-ops.md)
- "Get a second pair of eyes on this code or diff, then file the findings" → [adversarial-review.md](adversarial-review.md)
- "Host or consume a VA-private laya judge fine-tune (org/token/endpoint, publish contract)" → [laya-hf-hosting.md](laya-hf-hosting.md)
